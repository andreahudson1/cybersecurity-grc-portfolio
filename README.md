# Cybersecurity GRC Portfolio

This repository demonstrates a candidate GRC portfolio focused on three workstreams:

- healthcare-vendor-risk/
- iam-access-review/
- vulnerability-management/

This portfolio includes a fully populated synthetic example for the Healthcare Vendor Risk workstream and companion examples for IAM access review and vulnerability management. The artifacts are designed to show practical governance, risk assessment, remediation tracking, and executive communication.

## Notes
- All data is synthetic and safe to publish.
- This portfolio is intended to show how a GRC professional would assess risk, validate evidence, prioritize remediation, and present findings to both technical and executive audiences.

## How to review
1. Start with the healthcare-vendor-risk files.
2. Read `healthcare-vendor-risk/final-assessment-V001.md` for the executive summary and recommendation.
3. Use `healthcare-vendor-risk/workbook-instructions.md` to recreate the Excel workbook locally.
4. Review the IAM and vulnerability sections to see how the full GRC portfolio fits together.
