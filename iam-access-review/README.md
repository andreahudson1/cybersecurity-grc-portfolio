# IAM Access Review

This folder demonstrates a practical access governance review and recertification exercise.

## Objective
The goal of this work is to validate whether user access remains aligned with current roles, valid business needs, and security requirements.

## Scope
This example covers a quarterly review of employee and privileged access across finance, HR, IT, legal, and security functions.

## Key activities
- review access entitlements against current role assignments
- identify stale or obsolete access
- identify dormant accounts and orphaned access
- validate privileged access assignments
- document remediation and follow-up actions

## Included files
- `access-review.csv`
- `audit-findings.md`

## What this demonstrates
- access review skills
- role-based entitlement validation
- dormant account cleanup
- privileged access justification
- audit-ready remediation recommendations
